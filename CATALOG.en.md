# MotionGit illustrated template list

29 templates, 30 separate demo views. Each landscape or portrait entry has its own matching image, video and download route.

## Source code and download routes

Template 385712 is available for direct download and testing. Follow the included guide to get started, using the download route listed for each orientation.

We recommend downloading from MotionGit for connected asset matching, stickers, background music, and automatic template update checks and upgrades, making asset preparation and ongoing creation smoother. Follow the package guide and the needs of the current production.

The template source in official .motion downloads is also 100% open source. The code license and production guide are included in the package.

## How to use

1. Browse images and demos, then choose a template ID and landscape or portrait orientation.
2. Get the matching .motion from its download link or exact MotionGit template page; follow that page for the official edition.
3. Prepare the script, photos or video required by that template and give the package and materials to your assistant. Extract it, start with 00-START-HERE.md when present, then follow the included README and referenced production guide.
4. Reuse the working environment, fill only actual missing dependencies, make a real preview using the package guide, then export after review.

A `.motion` is an extractable template project. Use the included code and guide, insert the user’s materials and make a real preview.
