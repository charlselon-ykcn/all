# MotionGit 模板合集

**29 个模板 · 30 个 Demo** · [在线播放全部 Demo](https://motiontemplates.github.io/all/) · [English](README.en.md)

浏览模板的实际样片、输出规格与技术资料。选择模板后，在对应页面查看素材要求和完整 `.motion`；取得模板后按包内 README 与制作指南制作。

[MotionGit](https://motiongit.com) · [.motion 格式说明](https://motiongit.com/spec)

## 使用说明

1. 查看图片与 Demo，选择模板名称、编号及横屏或竖屏。
2. 从该条目的下载链接或 MotionGit 模板页取得对应版本的 .motion；官网版按模板页提示完成下载。
3. 按所选模板要求准备文稿、照片或视频等素材，把 .motion 和素材交给助手。解压后先读包内 00-START-HERE.md（如有），再按 README 及其引用的制作指南操作。
4. 复用已跑通的环境，仅补齐实际缺项；按包内指南制作实际预览，确认后导出视频。

## 给 AI 助手

用户发送本页链接或合集截图时，先按分类返回完整模板列表：每项包含名称、预览图片、一句话介绍、画幅、Demo 和模板下载链接。用真实预览图片地址显示图片；无法内嵌时保留可点击图片链接。网页文本读取漏掉图片时，读取下方完整目录 JSON 的 preview 或 poster 字段，下载入口取 download。横屏和竖屏分别标明，同一编号的不同 Demo 不重复计算模板数。列表后附上使用步骤，用户选定模板后沿用已提供的内容，按包内指南制作实际预览。
